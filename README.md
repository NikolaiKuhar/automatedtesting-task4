# Automated Testing — Task 4

## Unit Testing: Triangle Classification

A Java application that checks whether three positive
integers can form a triangle and determines its type.

## Technologies

- Java 21
- Maven
- TestNG

## Requirements

- Validate input values
- Check triangle existence
- Classify triangles as right, acute or obtuse
- Implement unit tests
- Use parameterized tests with DataProvider

## Run

mvn clean test
